### Principles

> Numbers in the core, strings at the boundary.

* derive abstractions from invariants and behaviour
* keep primitives small and reusable
* make data flow and failure boundaries explicit
* fail fast on invalid assumptions
* fall back explicitly where degradation is acceptable
* prefer measurable behaviour over claims
* avoid unnecessary representation changes and dependencies
* understand the runtime rather than hiding it
